# Yassine Hatouf — Technical Portfolio

Technical portfolio focused on **Data Science, Machine Learning, Backend Development, and Data Analytics**.

Built with **Astro, React, TypeScript, and Tailwind CSS**, and deployed with **GitHub Pages via GitHub Actions**.

## Featured projects

1. **California Housing ML** — regression project using Python, XGBoost, FastAPI, and Docker.
2. **HR Attrition Analysis** — predictive analytics and workforce analysis using Python, scikit-learn, and Power BI.
3. **HobbyBuddy** — full-stack matching platform combining Spring Boot, FastAPI, MySQL, authentication, and real-time communication.

## Portfolio features

- Technical project case studies
- Interactive skills visualization across Backend, Data Engineering, Machine Learning, and DevOps
- GitHub project integration
- Responsive UI and accessible semantic HTML
- Astro static generation with React islands for interactive components
- GitHub Actions deployment to GitHub Pages

## Tech stack

- **Frontend:** Astro, React, TypeScript, Tailwind CSS
- **Data / ML:** Python, pandas, scikit-learn, XGBoost
- **Backend:** Java, Spring Boot, FastAPI
- **DevOps:** Git, GitHub, GitHub Actions, Docker
- **Deployment:** GitHub Pages

## Development

```bash
npm install
npm run dev
```

Production build:
